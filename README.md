# GatherBuddyReborn

[GatherBuddyReborn](https://github.com/FFXIV-CombatReborn/GatherBuddyReborn) 的台服移植版，協助玩家進行採集、挖礦與釣魚。搭配 [vnavmesh](https://github.com/awgil/ffxiv_navmesh) 插件可實現全自動採集路徑導航。

## 功能

- **AutoGather 全自動採集**：自動導航至採集點進行採集/挖礦/釣魚並收滿指定物品（可同時排程多組滿疊），過程中自動換裝、精選（Aetherial Reduction）、修理裝備、附魂精、補充強心劑與食物，並具備防卡死機制（需要 vnavmesh）
- **資源佇列**：排入多項目標物品，依序自動採集
- **採集小窗（GatherWindow）**：自訂多組採集清單預設檔，快速切換目標
- **鬧鐘（Alarm）**：依採集點出現時間與天氣條件提醒
- **釣魚計時器（Fish Timer）**：顯示咬鉤時機與魚類判定，支援手動編輯模式
- **魚叉採集輔助窗**：輔助海洋魚叉採集判定
- **天氣頁**：查詢/快取各地天氣時段
- **採集組（GatherGroup）**：依時間輪替的採集清單
- **採集點清單**：可查詢的採集點資料
- **釣獲紀錄與統計**：記錄每次釣獲細節，並提供依採集點/魚餌/宇宙探索釣魚任務分類的統計頁
- **右鍵選單整合**：直接將物品加入鬧鐘或採集組
- **指令**：`/gbr`、`/gatherbuddy`（開啟主視窗）、`/gather`、`/gatherbtn`、`/gathermin`、`/gatherfish`（標記最近節點並自動傳送、換裝）、`/gathergroup`、`/gbc`（快捷開關）
